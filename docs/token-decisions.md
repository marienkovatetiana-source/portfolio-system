# Рішення щодо токенів (v2, мінімальний набір)

Правило: кожна роль має одне значення, кроків мало. Значення, що трапилось один раз, зводиться до найближчого токена. Значення, що повторюється й має свою роль, отримує токен за роллю. Набір — стартова точка, не стеля. Вихідні значення зняті з коду першого екрана старого портфоліо, не з Figma; їх ще перевіряємо візуально.

## Кольори: 7 ролей

| Було | Стало | Чому |
| --- | --- | --- |
| `#ffffff` | `canvas` | |
| `#fafafa`, `#f9f9f7` (картка) | `surface #f9f9f7` | майже однакові |
| `#e6e6e6`, `#dedede`, `#f0f0f0` (сітка) | `line #e6e6e6` | різниця непомітна, сітка декоративна |
| `#dffca1`, `#d8ff85` | `accent #dffca1` | майже однакові |
| `#0a0a0a`, `#171617`, `#094020` (іконка, hover, фокус), `#218500` (hover посилання) | `ink #0a0a0a` | сім ролей, не вісім. Іконка на accent: ink (17,5:1). Hover кнопки: ink з текстом accent. Фокус: ink. |
| `#545454`, `#6e6e6e`, `#999999` | `ink-muted #6e6e6e` | один приглушений тон (5,1:1 на canvas). `#999` не проходив контраст (2,85:1) |
| немає на макеті | `danger #b42318` | запропонований, відтінок червоний, не плутається з accent (5,6:1 на canvas) |

Межа поля форми й кнопки без заливки: `ink-muted`, не `line` (потрібно 3:1).

## Текст: 7 розмірів (орієнтир до дев'яти)

| Токен | Значення | Куди зведено |
| --- | --- | --- |
| `caption` | 14 / 1,4 / 400 | 13 (роль під портретом) |
| `label` | 14 / 1,4 / 500 | мітки меню 15, бейджі 15 і 14, номери «01», малі кнопки 14, бренд 15 |
| `body` | 16 / 1,5 / 400 | тип проєкту 15 |
| `button` | 16 / 1,25 / 500 | основна кнопка (повторюється, має роль) |
| `lead` | 22 / 1,45 / 400 | |
| `heading` | 20 / 1,3 / 600, трекінг −0,2 | назви карток 20, ім'я на портреті 18 |
| `display` | 56 / 1,1 / 600, трекінг −1,6 | головний заголовок |

Шрифти: `font-display` DM Sans (заголовки, кнопки, меню, бейджі), `font-text` Inter (решта). Два сімейства лишаємо, як на макеті.

## Радіуси: 2

- `control` 999 (pill): кнопки, бейджі, круглі іконки, аватар.
- `card` 28: картки, портрет, шапка, обкладинка в картці, плашка підпису. Вкладені 32, 20 і 18 злиті в 28.

## Відступи: 5 кроків + 1

8, 12, 16, 24, 32 (класи 2, 3, 4, 6, 8) і `section` 96 для відстані між великими секціями. Значення 4, 6, 10, 14, 28, 40, 48, 64 зведені до найближчого кроку.

## Інше

- Ширина контенту `page` 1200.
- Пропорції: `cover` 9/5 (обкладинка), `portrait` 4/5 (портрет), `avatar` 1/1.

## Відкрите

- Адаптивні розміри `display` (48 на ≤1200, 36 на ≤600) у токенах поки не закладені.
- Решту без візуала не вирішуємо: після Storybook зі сторінкою «Токени».
